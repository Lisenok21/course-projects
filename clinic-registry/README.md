# 🏥 Регистратура поликлиники

Курсовой проект по дисциплине «Технологии и методы программирования».
Научный руководитель: к.ф.-м.н., доцент Филиппов В.П.

## 📖 Описание

Консольное приложение для управления данными о пациентах поликлиники. Реализует класс `Patient` с полным набором полей и методов, обеспечивает добавление, поиск, сортировку, удаление и сохранение данных.

## 🎯 Цель работы

Изучение и применение принципов объектно-ориентированного программирования на C++, разработка проекта «Регистратура поликлиники».

## 🧠 Функциональность

| № | Функция | Описание |
|---|---------|----------|
| 1 | Поиск пациента | По подстроке (регистронезависимый) |
| 2 | Сортировка | По ФИО, полу, дате рождения, полису |
| 3 | Вывод всех | Отображение всех пациентов |
| 4 | Добавление | Ввод нового пациента с валидацией |
| 5 | Удаление | Удаление по номеру телефона |
| 6 | Выход | Завершение программы |

## 🔧 Валидация данных

- `isValidFullName()` — ФИО (3 слова, только кириллица)
- `isValidDate()` — дата в формате ГГГГ-ММ-ДД или ДД.ММ.ГГГГ
- `isValidPhoneNumber()` — телефон (`+` и 10+ цифр)
- `isValidPassportData()` — паспорт (4 цифры, пробел, 6 цифр)
- `isValidInsurancePolicy()` — полис (10 цифр)
- `isValidAddress()` — адрес (не пустой)
