# 🖼 Стеганография в цифровых изображениях

Курсовой проект по дисциплине «Методы и средства криптографической защиты информации».
Научный руководитель: к.ф.-м.н., доцент Христофорова А.В.

## 📖 Описание

Программная демонстрационная система для сравнения методов стеганографии в цифровых изображениях. Реализует классический метод замены младших битов (LSB — Least Significant Bit) в синем канале изображения.

## 🎯 Цель работы

Разработка демонстрационной системы, позволяющей реализовывать и сравнивать методы стеганографии в изображениях, анализировать их характеристики.

## 🧠 Теоретическая база

Классификация методов:

- Пространственные: LSB, PVD, GLM, MVP
- Частотные: DCT, DWT

### Сравнение методов

| Характеристика | LSB (синий канал) | LSB (все каналы) | Замена битов чётности |
|----------------|-------------------|------------------|----------------------|
| Ёмкость (Full HD) | ~0.3 МБ | ~0.9 МБ | ~0.1 МБ |
| Стойкость к обнаружению | Средняя | Низкая | Высокая |
| Визуальная заметность | Низкая | Средняя | Очень низкая |

## ⚙️ Формат данных

В изображение встраивается:

- 32-битный заголовок (длина сообщения в байтах)
- Данные сообщения (N байт × 8 бит)

Ключевая операция замены бита:

```python
b = (b & 0b11111110) | bit
```

## 🚀 Использование

### Установка зависимостей

```bash
pip install Pillow
```

### Встраивание сообщения

```bash
python stego.py encode input.png output.png "Секретное сообщение"
```

### Извлечение сообщения

```bash
python stego.py decode output.png
```

## 💡 Пример работы

```bash
$ python stego.py encode test_image.png secret.png "Hello world!"
Сообщение длиной 12 байт встроено в 'secret.png'.

$ python stego.py decode secret.png
Считано сообщение длиной 12 байт:
Hello world!
```
