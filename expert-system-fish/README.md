# 🐟 Экспертная система «Рыбы»

Курсовой проект по дисциплине «Экспертные системы».
Научный руководитель: к.т.н., доцент Обломов И.А.

## 📖 Описание

Экспертная система для классификации видов рыб на основе их характеристик. Система использует логический вывод для определения вида рыбы по набору признаков, задаваемых пользователем в диалоговом режиме.

## 🎯 Цель работы

Разработка экспертной системы, которая сможет классифицировать виды рыб на основе их характеристик и взаимодействия с пользователем.

## 🧠 База знаний

Система распознаёт 7 видов рыб:

| Вид | Класс | Признаки |
|-----|-------|----------|
| Химера | Хрящевые | Цельная голова, острые зубы, крыловидные плавники |
| Акула | Хрящевые | Пластиножаберные, острые зубы, хороший нюх |
| Скат | Хрящевые | Пластиножаберные, крылья, длинный хвост |
| Сельдь | Костные (морские) | Кости, большая чешуя, полосы |
| Лосось | Костные (морские) | Кости, циклоидная чешуя, пятна |
| Треска | Костные (морские) | Кости, маленькая чешуя, усы |
| Карп | Костные (речные) | Кости, мало чешуи |

## 🌳 Структура предметной области
Рыбы
├── Хрящевые
│   ├── Цельноголовые → Химеры
│   └── Пластиножаберные → Акулы, скаты
└── Костные
    ├── Морские → Сельдь, лосось, треска
    └── Речные → Карп
